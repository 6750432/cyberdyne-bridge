## 2. 基础反射层

### 实现

优先级（安全第一）：

```
敌人贴脸(<5格)  →  逃跑（全速后退）
     ↓ 若同时血<20% 且背包无食物
                  →  濒危（慢速后挪，不恋战）
血<50% 且有食物  →  进食
血<20% 且无食物  →  原地不动，脱离战斗
其余             →  平静
```

逃跑方向不是"背对最近的敌人"，而是把**身边每个敌人都当成一个推力求矢量和**（权重 = 1/距离），这样被两只怪夹住时会往空隙钻，而不是撞进其中一只怀里。M1 只有这个力场，没有寻路。

### 实测记录（真实日志摘录）

**① 逃跑反射** —— 召唤一只僵尸到 4.1 格：

```
[19:28] 呜呜，有个僵尸靠近我（4.1 格），我赶紧往后跑！
```
坐标从 `(2, 80, -4)` 一路退到 `(-28, 69, -1)`，**实际后退了约 30 格**，僵尸被甩开。

**② 进食反射** —— 先用饥饿效果把饥饿条压到 16，再打掉 11 点血：

```
[19:35] 哎哟，挨了 11 点伤害，血 13.5 → 2.5/20
[19:35] 肚子饿了（血 3/20，饥饿 16/20），我翻出面包吃一口。
[19:35] 吃完啦，长舒一口气。
```
之后血量自己从 2.5 回到 13。**并且发现并修正了一个真实设计缺陷**：MC 的规矩是肚子饱着（foodLevel=20）根本不让吃，硬吃只会报 `Food is full`。所以脑子现在会先看饥饿条：

```
[19:35] 血只有 3/20，不过肚子是饱的 —— 饱着就自己回血，用不着吃，我先等着。
```

**③ 濒危反射** —— 血 2/20、背包被清空、僵尸贴到 1.4 格时：

```
[19:57] 呜…我快不行了（血 2/20），背包里一点吃的都没有，「僵尸」离我只有 1.4 格——
        我不能打，只能慢慢往后挪。
```

### 额外的保命闸（超出清单，但直接服务于"能自保"）

逃跑前会看正前方一格的脚下：**是岩浆/火/仙人掌/细雪，或者往下两格还是空的（断崖），就不往那边跑**，会左右各试 60°/120° 找一条能走的路；四条都不行就原地站住并广播 `blocked` 事件。没有这道闸，一次夜间逃跑就可能把它送进岩浆。

> 说明：这不算越级做寻路 —— 它只判断"下一格能不能踩"，不规划路线。

## 3. 防卡死

| 项 | 实现 | 实测 |
|---|---|---|
| **10 秒无状态即重连** | 脑侧记 `上次状态时刻`，超时断开重连 | 测试期内 **0 次触发**（接线口一直健康） |
| **Socket 断了自动重连** | 脑侧外层循环 + 退避阶梯 `2/4/8/15/30` 秒 | 实测触发 **3 次**（见下），每次都自己爬回来 |
| **小家伙掉线自动回世界** | 手侧 `bot.on('end')` → 阶梯退避重连 | 实测触发 **1 次**（服务端重启时），自己回来了 |
| **倒下自动重生** | 手侧 `bot.on('death')` → 1.5 秒后申请重生 | 实测触发 **3 次**，**每次都成功站起来** |
| **异常数据包丢弃** | 逐行 `try/JSON.parse`，坏包计数 + 限频告警，超 64KB 直接砍缓冲 | 测试期内 **0 个烂包**（设计了但没机会触发） |
| **大脑兜底** | 主循环最外层 `except Exception`，任何意外都不许把大脑带走 | 实测触发 **3 次**，全部来自下面的真 bug，大脑一次没崩 |

### 实测抓到的真 bug（已修）

第一次长跑时大脑连续报：

```
[19:29] 大脑内部出了个意外（ValueError: Unknown format code 'd' for object of type 'float'），
        我断开重连，继续盯着。
```

**根因**：MC 的血量是**浮点数**（打一下可能掉 1.5），我在叙事里写的是 `{差:+d}`，整数格式化遇到浮点直接抛异常。

**修的**：加了一个 `血文本()` 辅助函数（整数不带小数点、小数保留一位），全文件再也没有 `:d`。同时借这个机会把血量播报做了合并 —— 挨打时每秒都在掉，逐帧报会滚屏，现在攒够 2 点或隔 4 秒才开口。

**这次事故反而是防卡死设计的最好证据**：异常抛出来了，大脑没有崩、没有退出，而是自己重连后继续干活，主人在终端上看到的是三行中文说明而不是一段 Python 堆栈。

## 4. 叙事化日志

### 做法的四条

1. **任何情况下都不打印原始 JSON**。原始行只在 `--json` 排查开关下才出现。
2. **说人话**。所有事件都有一句中文：敌人来了叫什么名字、挨了几点伤害、吃的是什么、为什么不吃。
3. **限流**：每分钟最多 12 条（紧急事件放宽到 4 倍，也就是 48 条），超出的压掉并计数，下次开口时交代"（期间压掉了 N 条啰嗦的）"。**紧急不等于无限**。
4. **合并**：位置变化在动作进行中不报（否则一次逃跑能刷几十行）；血量变化攒够再报；自然回血 10 秒才报一次。

实测一天下来，26 分钟的长跑只产生 **84 行**日志，平均每分钟 3.2 行 —— 不滚屏。

### 几个例子

[20:00] 视野里出现了「enderman」，15.1 格远
[20:01] 「skeleton」走开了
[20:07] 他还在 (8, 81, 4)，身边有 mintstar(8格)、skeleton(11格)｜血 20/20｜已经待了 18分9秒
[20:10] 哎哟，挨了 3 点伤害，血 5.9 → 2.8/20

## 6. ⚠️ 没达标的地方：测试期内死了 3 次

**这是本次测试最需要主人知道的事实。** 三次死亡全部集中在 **19:56–19:57 的一分钟之内**，之后 13 分钟再没死过。

### 现场

```
[19:56] 哎哟，挨了 3 点伤害，血 5.9 → 2.8/20
[19:56] 哎哟，挨了 3 点伤害，血 2.8 → 0/20
[19:56] 他倒下了。
```

### 根因（三条叠加，不是单一 bug）

1. **起跑血就不满**。19:35 那次进食反射测试把它打到 2.5/20，之后只回到 12/20 就进入夜间，**不是满血开局**。
2. **死亡会掉光背包**。MC 的规矩是死了东西全掉。它第一次死时把 24 块牛排、24 个面包和整套铁甲全丢了 —— 于是第二次、第三次是**裸着挨打**，而且「背包里一点吃的都没有」，连进食反射都无从下手。
3. **僵尸贴到 1.4 格时逃跑已经来不及**。反射层的判定是 5 格触发，但 1 Hz 的状态采样（每秒一拍）意味着最坏情况它反应过来时怪已经在脸上，一秒钟能挨两下。

### 客观评价

- 反射层**每一次都正确触发了**，日志上写得清清楚楚（逃跑 6 次、进食 1 次、濒危 2 次），没有一次是"该跑没跑"或者"该吃没吃"。
- 它输在**手段只有"跑"这一种**。M1 不允许攻击、不允许寻路、不允许造掩体，所以被逼到墙角就是必死 —— 这是能力边界，不是实现缺陷。
- 死亡后**自动重生机制工作正常**，三次都自己站起来了，现在也是满血 20/20 活着。

### 建议（M2 再议，本次没做）

| 建议 | 理由 |
|---|---|
| 逃跑时**同时给背包留一份"应急粮"**（不放快捷栏、专门存一格） | 死了不至于连吃的都没了 |
| 增加**掉血后主动拉开距离**（不只等敌人进 5 格） | 把主动权拿回来，别等贴脸 |
| 增加"**原地搭柱子/挖坑**"这类防御动作 | 被围住时唯一的活路 |
| 状态推送从 1 Hz 提到 5 Hz（仅在被追时） | 把反应延迟从 1 秒压到 200 毫秒 |
