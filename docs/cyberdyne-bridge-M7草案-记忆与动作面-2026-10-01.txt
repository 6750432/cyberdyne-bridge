# M7 草案 · 记忆与动作面（让它从「遛弯」变成「有打算」）

> 一句话题目：**给它一个"记得住"的脑子 —— 记得家在哪儿、哪儿有矿、
> 上次那条矿道没挖完 —— 再把手上的活儿从"挖和捡"扩到"合成和开箱子"。**

由来（主人 2026-10-01 问「他现在会自己玩了吗」，我如实回答之后）：
> 「它现在会自己玩，但玩得像只小狗在院子里转悠，不像个有打算的伙伴。
>  缺的就是两样：**记忆**和**更宽的合法动作面**。」
主人：**「那你想想 M7 怎么做。」**

---

## 一、目标与非目标

**目标**
1. **M7a·记忆**：四类"小卡片"（地点 / 事件 / 人 / 未了事），会写、会合并、会淘汰、
   能被**检索出来塞进 prompt** —— 让它下一次心跳的目标能接得上上一次。
2. **M7b·动作面**：把 M4c 任务栈的允许动作扩两个 —— **合成** 与 **箱子存取**，
   让"砍树 → 做镐子 → 去挖矿"这条链第一次成为可能。

**非目标**
- 不做"全量日志式记忆"（日志照旧全量留在 `logs/`，那是**证据**；记忆只留以后用得上的）。
- 不做向量检索/RAG（几百张卡片的线性扫描是微秒级，杀鸡不用牛刀）。
- 不做"记忆自己发明关系"（是不是敌人/朋友，永远由既有名单说了算，记忆只记事实）。
- 不做盖房/种地/跑图探索（那是 M8 以后的事）。

---

## 二、现状缺口（拿 M6 验收的实拍说话）

心跳那次它自己定的目标是：
> 「**在附近找点能捡的小东西**」——理由「主人让我自己找点事做，我就在附近转转」
> 「**在附近转转看看有什么**」——理由「先熟悉一下周围环境」

目标没问题，但**短视**：它每次心跳都是从零开始 ——
不知道家在哪、不知道哪儿有矿、不记得昨天干过什么、也不记得"上次那件事没干完"。
**记忆就是补这个的。**

## 三、M7a · 记忆：四类小卡片

存放：`~/cyberdyne-bridge/记忆/`（**JSONL，追加写**，老规矩；带 `世界` 字段以防将来多个世界串味）
每张卡都记：`第一次见 / 最后见 / 见过几次 / 来源（扫描·自己干·主人说）/ 可信度`

| 卡片 | 记什么 | 从哪儿来 | 例 |
|---|---|---|---|
| **地点** | 类型（家/床/箱子/熔炉/工作台/矿/树/水/岩浆/危险）+ 坐标 | ① 扫描里的"可交互" ② 自己挖到矿时 ③ 主人一句话 | `{类型:"矿·铁矿", 坐标:[-25,64,-25], 见过:3, 来源:"自己挖到"}` |
| **事件** | 类型（任务完成/任务失败/被打/卡住/重生/第一次做某事）+ 坐标 + 摘要 | 任务栈的账 + 手感（`attacked_by`/`stuck`） | `{类型:"任务失败", 摘要:"挖基岩挖不动", 坐标:[20,77,-18]}` |
| **人** | 名字 + 事实计数（跟我说过几次话 / 打过我几次 / 给过我东西）+ 最后见 | 聊天事件 + `attacked_by` | `{名字:"mintstar", 说话:12, 打我:0, 最后见:"刚刚"}` |
| **未了事** | 上次没干完/干失败的活（任务名 + 停在第几步 + 原因 + 坐标） | 任务失败 / 中止 / 被打断超时 | `{任务:"挖 3 格再回来", 停在:2, 原因:"被打断 41 秒", 坐标:[10,77,10]}` |

**写入规则（都发生在"事情刚发生"时，不轮询、不回头算）**
- 扫完一圈 → 把"可交互"炼成地点卡（**半径 8 格内同类合并**，不重复记）
- 任务成功/失败/中止 → 事件卡；失败与中止**额外**写一张未了事卡
- 挨打 → 人卡"打我 +1"；说完话 → 人卡"说话 +1"
- 第一次挖到某种矿/第一次做某件事 → 事件卡（"第一次"这种事很值钱，目标生成爱用）

**合并与淘汰（防无限涨）**
- 同类地点在 8 格内 → 合并（`见过+1`、更新 `最后见`）
- 每类容量：地点 400 / 事件 800 / 人 200 / 未了事 50（都能配）
- 满了就淘汰"**最久没见过 + 见过次数最少**"的；**未了事优先保留**（它是"惦记"）
- 事件卡按"重要度"保留：失败/被打 > 普通完成

**检索（喂给 LLM 的那一口）**
- `附近(半径)` → "我记得周围有：熔炉(20,78,-20)、箱子(21,78,-20)、铁矿(-25,64,-25)…"（≤5 条）
- `未了事()` → "上次那条「挖 3 格再回来」停在 2/11 步，因为被打断"（≤2 条）
- `这个人(名)` → "mintstar：跟我说过 12 次话，没打过我"
- `最近(时间窗)` → 最近几件大事（≤3 条）

**注入 prompt**：在【触觉】后面加一段【记忆】（**≤8 行 / ≤300 字**），
心跳和闲聊都会带上 —— 这就是"目标变得连贯"的机制。
实测成本估算：+300 字 ≈ +225 token/次（心跳一次约 700 → 925 token）。

**记忆不许干的三件事（红线）**
1. **记忆不是指令**：它只进 prompt，**永远不许**直接触发动作；一切动作照旧过 fail-closed 校验器。
2. **不许发明关系**：是不是敌人/朋友只认既有名单；记忆只记"他打过我几次"这种**事实**。
3. **不存聊天原文**：人卡只记名字、次数、时间（隐私 + token 双省）。

## 四、M7b · 动作面：合成 + 箱子存取

手上其实**已经有** `craft`（合成）和 `use`（箱子·按钮·门）两个能力（M4a 就在插件里），
缺的是"让任务栈能安全地用它们"：

| 新动作 | 参数 | 完成判据（看事实） |
|---|---|---|
| 合成 | 物品 + 数量 | 物品探针里数量够（跟"拾"同一条判据） |
| 箱子里取 | 箱子坐标 + 物品 + 数量 | 物品探针够数 |
| 往箱子里放 | 箱子坐标 + 物品 + 数量 + 保留几个 | 物品探针降到目标值 |

**安全约束**：只能碰**自己的**箱子？—— 不，只能碰"记忆里标为**我的**箱子"或"主人放的那几个"。
第一版：**箱子操作只对"扫到过的箱子"生效**（扫过 = 它见过、位置明确），
绝不允许对没见过的坐标动手（防 LLM 乱指）。**不许放/取危险物品清单**（打火石、TNT 之类先拉黑）。

## 五、验收点（都拿数据验）

| # | 场景 | 期望 |
|---|---|---|
| A | 地点记忆 | 扫一圈 → `记忆/地点.jsonl` 出现卡片；再扫一次 → **合并成同一条**（见过 +1），不重复记 |
| B | 附近检索 | 问它「这附近有啥」→ 推给 LLM 的 prompt 里【记忆】段有"我记得周围有…"（≤5 条） |
| C | 事件记忆 | 干完一个任务 → `记忆/事件.jsonl` 一条"任务完成"卡（含坐标/任务名/用时） |
| D | **未了事** | 故意让任务失败 → 生成未了事卡；**下一次心跳的 prompt 里出现它**，且它定的目标**提到了那件事**（这就是"连贯"的实证） |
| E | 人记忆 | 被假人打几次 → 人卡"打我 +3"；主人说话 → "说话 +1" |
| F | 淘汰 | 把容量调小 + 灌满 → 只留"最近见过/次数多"的，文件不无限涨 |
| G | 红线 | 安全检查新增断言：记忆模块里**没有**任何动作/执行能力；一切动作仍过校验器；prompt 里【记忆】段有长度上限 |
| H | M7b 动作面 | 合成一把石镐 / 从箱子取东西、往箱子放东西 —— 三条都验过（离线的判据 + 现场各一次） |
| I | 回归 | 三觉 55 / 任务 64 / 猎手 71 / 指令 49 / 安全（+1）全过；回放基准一致 |

## 六、开关与回滚

| 开关 | 默认 | 关掉之后 |
|---|---|---|
| `m7.memory_enable` | true | 不写不读记忆，prompt 回到 M6 的样子（心跳照旧能跑，只是目标又变短视） |
| `m7.memory_in_prompt` | true | 只在本地记，暂时不往 prompt 里塞（先攒着看） |
| `m7.expand_actions` | **false** | 合成/箱子不进允许清单（先只做记忆，动作面下一轮开） |

改动集中在：`bridge.py`（新类 `记忆` + 三处写入钩子 + prompt 注入）、
`node/plugins/body/proto_body.js`（箱子取/放两个能力，craft 已有）、
`config.json`（m7 一节）、`tools/测记忆.py`（新回归）。
