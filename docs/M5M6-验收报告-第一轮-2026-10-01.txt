一、这一轮做了什么
----------------------------------------------------------------
· **手侧**：新增 `scan_environment`（视觉）与 `scan_clear`；快照新增
  `durability`（手持 + 四件护甲，用 `item.durabilityUsed/maxDurability`）与
  `scan`（时间/昼夜/天气/群系/脚下/方块统计/地面/可交互/危险/实体）。
  全是**纯读**，不动世界、不加依赖。
· **脑侧三个新类**（都**没碰**反射层与任务栈）：
  - `三觉`：视觉（扫描→中文摘要，≤8 行 600 字）/ 听觉（最近 6 条聊天 + 指令标记）/
    触觉（疼·饿·装备快坏·背包·没工具·卡住·挨打·天黑·没事干 → 人话）
  - `翻译器`：上行组 prompt（硬上限 1200 字）；下行 **fail-closed 校验器**
  - `心跳`：M6 自主找事（六条点火条件 + 预算 + 空转退避 + 审计）
· **接线**：聊天先过指令层 → 记进听觉窗 → 认不出且是主人/好友 → 走"闲聊"路；
  状态帧之后记空闲 → 心跳看一眼。反射层位置**没动**（永远最先）。
· **两条宪法**进了 `tools/安全检查.py`（17 条断言）：
  ① 单步白名单里**没有任何攻击类动作**；② 任务书里**显式禁止「打」步骤**且校验器真的会拒。

**B 的完整链路**（听觉 → 云端 → 游戏里说话）：
```
你「今天跑了好远，腿有点酸」
→ 指令层：认不出
→ 听觉窗 + 三觉 → prompt（767 字）
→ deepseek：{"act":"say","text":"腿酸就歇会儿嘛～我陪你在这儿漂着…"}
→ 校验器：放行（say 在白名单里）
→ 它真的在游戏里说了这句
```
顺带验到：**上下文窗是活的** —— 下一轮它回话时还记着「你腿酸就歇会儿」。

**E 的完整链路**（心跳 → 目标 → 任务栈 → 执行）：
```
你说「自己找点事做」→ 心跳开关打开
→ 60 秒内没人说话、它平静、没任务
→ 心跳点火：三觉 → prompt（890 字）→ deepseek
→ {"任务":{"名字":"在附近找点能捡的小东西","为什么":"…","步骤":[6 步]}}
→ 校验器：接单（步数 ≤6、动作都在允许清单里、坐标都在 64 格内）
→ 任务栈执行：跑完 9.4 秒 ✓
```

三、成本实测（主人最在意的）
----------------------------------------------------------------
· 上行 prompt 实测 **767~932 字 ≈ 575~700 token**
· 本轮验收一共 6 次成功调用（3 闲聊 + 3 心跳）≈ **3885 token**
· 满打满算（心跳 60 秒一次、每次 900 字）≈ **20 万 token/天**；
  但点火条件卡住了大部分时间（主人在线 + 平静 + 没任务 + 最近没人说话），
  实际会稀得多 —— 而且**默认是关的**，开关在主人手里。

四、这一轮现场抓到并修掉的 4 个 bug
----------------------------------------------------------------
1. **`能问()` 被我用错**（多传了个参数）→ 闲聊第一次直接把大脑干重启了一次
   （兜底：断线重连继续盯，没崩）。
2. **`x or '?'` 的坑又踩一次**：MC 第 0 天是 `0`，被当成"没有" → 日志里出现
   「第 ? 天」。手侧踩一次、脑侧又踩一次，现在两处都改成显式判 `None`。
3. **视觉摘要被石头刷屏**：原来抽样范围含地下（dy -3~5）、兴趣方块表里还塞了
   `stone` → 摘要里除了 stone 什么都看不见。改成：只看脚上下三格 + 地面单独报
   + 兴趣表去掉遍地都是的东西。
4. **模型把任务步骤写成了字符串**（`"走到(p=[10,78,10])"`）→ 被校验器拒。
   按老经验「**加例子有效、加规则有害**」，在心跳 prompt 里塞了一个**完整 JSON 例子**
   → 立刻就能生成合法任务书了。
