## 二、六个发现（按重要性排）

### 🔴 发现 1：它读到了你的血，但**只用来念台词**

上面那段原文就是铁证：它**明确看到「他还有 4 血」**，然后还是挥了下去。

**这是整场测试最重要的一条：读到了不用，等于没读。**

探针辛辛苦苦把对手血量读进 `watched` 字段，但 M2 里这个数**只出现在叙事文本里，一个判断都没参与**。
结果就是：它把主人打到 4 血，再一刀打死。

**取舍点**：对手血量该不该参与决策？参与的话怎么用？
- 对**真敌人**（僵尸、骷髅）：血量只影响「打不打得过」的判断
- 对**被标记的玩家 / 队友 / 宠物**：血量应该触发**手下留情**
- 但 M2 里**没有「这是自己人」这个概念** —— 这正是要定的取舍

---

### 🟠 发现 2：76% 的出手都挤在 2.5 格 —— 一条「僵持带」

出手距离分布（67 次反击）：

```
2.5 格  ███████████████████████████████████████████████████  51 次  (76%)
3.0 格  ████████                                              8 次
2.0 格  ████                                                  4 次
1.5 格  ██                                                    2 次
1.0 格  █                                                     1 次
0.0 格  █                                                     1 次
```

**为什么是 2.5 格？因为逃跑速度和追击速度一样（都是 4.317 格/秒）。**

主人追上 → 它开跑 → 两边同速 → 距离被冻结。而反击线（3.0 格）和逃跑线（5.0 格）一夹，
就形成一条 2.5 格左右的**僵持带**：它在这个距离上反复"够得着又够不着"地挥空。

**这条带是数学的产物，不是设计出来的。**

### 🟠 发现 3：命中率低 —— 67 次挥击，主人只掉了大约 12 次血（约 18%）

而且**打得中的时候距离明显更近**：

```
掉到 15.0 血  ← 它出手时距离 2.3 格
掉到  9.0 血  ← 2.0 格
掉到  4.0 血  ← 1.4 格
```

⚠️ **必须诚实说：我没法从日志里确定命中率低的确切原因。**

因为——**现在一次成功的挥击是不留痕的**。日志只记「它宣告要打」，
不记「它这一下到底打中没有」。回执是 `ok:true`，但那是"命令发出去了"的意思，
不等于"这一下造成了伤害"。

我只能说：出手大量发生在 2.5 格，而 MC 的实际攻击距离约 3 格，
**叠上移动延迟就很容易落空**。要查清楚，得先补日志。

**→ 这本身就是 M2 的一个日志缺口。**

---

### 🟠 发现 4：紧急日志把正常日志**饿死了** ——「跑」在日志里消失了

```
反击宣告 67 次 | 后撤宣告 2 次      ← 这两个数应该 1:1
```

根因：限流器里**紧急额度和正常额度共用一个滑动窗口**。

- 反击宣告走 `紧急=True` → 额度 12×4 = 48 条/分
- 「退两步」走普通 → 额度 12 条/分
- 战斗时窗口里已经堆了 20+ 条，**普通额度一次都挤不进去**

于是「退两步」这句被打掉了。**命令其实照发了**（代码里 `发命令` 在 `说` 前面），
但**日志没记下来**。后果很严重：

> 事后复盘时，你根本看不出它有没有真的执行「打了就跑」的"跑"。

---

### 🟡 发现 5：日志刷屏 —— 战斗时 19~28 行/分，顶穿了 12 条/分的正常限流

而且有一段是 **41 次一字不差的重复**：

```
41 次   距离 2.4 格 / 它 18.7 血 / 你 20 血      ← 数值完全没变
```

原因：反击每 2.5 秒一次（`counter_cooldown_ms`），而**每次都要宣告一嗓子**。

---

### 🟡 发现 6：这场胜负本身没有意义

主人是**空手**，小家伙是**整套铁甲 + 铁剑**。

| | 一下伤害 |
|---|---|
| 主人空手打它 | 约 **0.85**（打 11 下它掉 9.4 血） |
| 它铁剑打主人 | **6** |

**测试设计上不对等。** 下次要么给主人对等装备，要么让它空手。

## 三、它做对的（不能只批评）

### ✅ 血量门槛真的在救命

它被打到 **5/20**（低于 12）之后**立刻不还手了**，改成一味逃跑：

```
[22:26] 哎哟，挨了 1 点伤害，血 5.9 → 5/20
[22:26] 呜呜，有个mintstar靠近我（3.3 格），我赶紧往后跑！
```

**这正是任务书里「血 ≤ 12 不还手」那条规则在实战里生效。**
要是没这条门槛，它会在 5 血的时候还站在那儿对砍，早死了。

### ✅ 采样速率跟着战况走

交战切 5Hz、打完自己降到 1Hz，一共切了 5 次，两边读数一致。

### ✅ 三道防线一次没破

烂包 0 / 大脑内部意外 0 / 热挂起 0。**5Hz 的高频状态下也没出过一次异常。**

### ✅ 自动重生干净利落

主人死后它没愣住，立刻切回平静档；主人复活回来它又正确切回战斗档。

## 四、取舍建议（请主人拍板）

| # | 问题 | 建议 | 代价 |
|---|---|---|---|
| **1** | **对手血量读到了不用** | 加一条「对手血低于 X 就收手」。但前提是先有**「这是自己人」**的判断 | 需要引入"友方"概念，M2 没有 |
| **1b** | 更保守的替代方案 | **只对真敌人用血量**，对被标记的玩家一律不启用反击 | 功能变窄，但对练安全 |
| **2** | 76% 出手挤在 2.5 格 | 把 `counter_dist` 从 3.0 **收到 2.0** —— 够不着就别挥 | 出手次数大减，但命中率会上去 |
| **3** | 逃追同速导致僵持 | 后撤时**开疾跑**拉开距离 | 掉饥饿；现在 `sprint_when_flee=false` |
| **4** | 日志刷屏 | **数值没变就不宣告**；同一个目标的连续出手合并成「又挥了 N 下」 | 少了过程感 |
| **5** | 紧急饿死正常 | **两套额度分开算**，紧急的不挤占正常的 | 限流器稍微复杂一点 |
| **6** | 挥击不留痕 | **每次挥击记一条结果**（打中／落空／够不着） | 日志多一条，但可以靠第 4 条的合并压住 |

### 我的倾向（供参考）

**先做 6 → 5 → 4，再做 2，最后才碰 1。**

理由：**前四条都是"把眼睛擦亮"，第 1 条是"改决策"。**
在一个连"打中没打中"都看不见的系统上改战斗决策，等于闭着眼睛调参。

至于第 1 条，我个人倾向 **1b（保守版）**——
「谁是自己人」这个问题 M2 根本回答不了，
在回答不了之前，**不该让小家伙对玩家用"能打死人"的那套逻辑**。
