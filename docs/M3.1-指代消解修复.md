# M3.1 · 指代消解修复

**触发**：主人实测反馈 —— 「跟紧我」被解析成了「我跟着 XiaoJiaHuo（它自己）」
**日期**：2026-09-30 23:28 – 23:33

---

## 一、先说根因：不是"提示词没写清楚"

复现（`logs/llm审计.jsonl` 原文）：

```
「跟紧我，别走丢了」 → follow who=XiaoJiaHuo     ★ 它自己！
「跟紧我别走丢了」   → follow who=mintstar       ✓ （我改完措辞之后）
```

**两条链路对代词的处理方式完全不同：**

| | 代词在哪一步被消解 | 结果 |
|---|---|---|
| 指令层（规则） | 模板里硬编码 `who=说话人` —— **编译期就消解了** | ✅ 永远对 |
| 大模型层 | 整句原封不动（带着「我」）丢给云端 —— **要它自己猜** | ❌ 会猜错 |

**「我」到底指谁，是一个指代消解问题。**
把它丢给大模型猜，等于让它替我们做语言学的活 —— 而且猜错了**没有任何东西拦得住**。

## 二、我上一次的"修法"是假的

我第一次发现这事，改的是**提示词措辞**：

```
+ f"正在跟你说话的人是「{说话人}」—— follow 里的 who 默认就填他，"
+ "除非他明确点名要你跟着别人。你自己叫「" + 自己名 + "」，别跟着自己跑。"
```

然后测了一次，看着对了，就收工了。

**这是把 bug 藏起来，不是修掉它。** 加一句叮嘱只是在求它别犯错 ——
换个句式（「跟紧我」「别跟丢了」「你跟着我走」）照样可能翻车，
而且翻车了也看不出来，因为它不报错、不抛异常，就是安安静静地做错事。

---

## 三、真正的修法：在**边界上**做归一

新增 `代词` 类。**归一必须在任何下游层之前完成** —— 下游压根不该看到代词。

### 消解规则

| 代词 | 换成 |
|---|---|
| 我 / 咱 / 俺 / 我们 / 我自己 | **说话人** |
| 你 / 您 / 你自己 | **自己**（小家伙） |
| 他 / 她 | 在场第三方**唯一**时才敢认；不唯一就原样留着，不猜 |

三条设计取舍：

1. **顺序要紧** —— 「长的排前面」，否则「我自己」会被「我」先切一刀，
   剩下一个「自己」就没人处理了。
2. **第三方不敢乱认** —— 场上有小明和小红时，「他」指的是谁真的说不准，
   **宁可不认**，也不猜一个错的。
3. **误伤词要罩住** —— 「其他」「其它」「我的世界」里含代词但不是代词，
   先拿占位符罩起来，换完再放回去。

### 效果（离线可复现）

```
原文                     说话人      归一后                     换掉了
──────────────────────────────────────────────────────────────────────────
跟紧我，别走丢了          mintstar   跟紧mintstar，别走丢了         我→mintstar
你过来一下                mintstar   XiaoJiaHuo过来一下          你→XiaoJiaHuo
跟着我别跟丢              mintstar   跟着mintstar别跟丢           我→mintstar
去找他                    mintstar   去找他                       （没换 —— 场上有两个第三方）
```

**大模型现在根本看不到「我」** —— 它看到的是「跟紧mintstar，别走丢了」。

### 真机验证

```
[23:31] 「mintstar」说「跟紧我，别走丢了」—— 这句我没学过，先老实说不会，绝不乱动。
[23:31] 我先把代词认清楚：我→mintstar          ← ★ 这一句是新增的，可审计
[23:31] 大模型把它翻成了「follow」，我照着做。
```

审计日志（现在连归一结果一起记）：

## 四、第二道锁：荒谬性校验

归一之外，还加了一条**专门用来拦这类错误**的检查：

```
follow 的 who 不能等于自己
```

```
[23:31] 它让我跟着我自己跑 —— 这说不通，拒了。
```

理由：**跟着自己跑在语义上就是荒谬的。**
哪怕将来归一逻辑被改坏了、或者大模型又抽风，这一条都能兜住 ——
而且它不是"猜"，是一个**可以证明的错误**。

这类检查值得多写几条：**用"说不通"来兜底，比用"再叮嘱一遍"可靠得多。**

新增 `tools/测指令.py`。**不花钱、不连网、不连游戏**，纯离线断言。

```

**那个 bug 用例就钉在里面：**

```

以后谁碰了代词或模板，跑一下就知道有没有退化。

## 六、这一轮真正学到的东西

**1. 加叮嘱 ≠ 修 bug。**
第一次我是改提示词，现在是改数据流的位置。**前者求它别犯错，后者让它没法犯错。**

**2. 有歧义就明说，别让下游猜。**
指代消解是**边界上的事** —— 谁说的、对谁说，这个上下文我们手里就有，
根本不该漂到云端去。

**3. 用"说不通"兜底。**
「跟着自己跑」荒谬、「跑 700 格」荒谬、「跟一个看不到的人」荒谬 ——
这三条都成了校验规则。荒谬性检查比"再叮嘱一遍"可靠得多。

**4. 可审计才叫修好。**
现在每次归一等于是"我先把代词认清楚：我→mintstar"，
**换错了当场看得见**，不用事后猜它为什么犯傻。
