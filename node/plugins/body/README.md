# 身体插件（proto_body.js）

手 + 腿。**全部本地确定性逻辑，不经过任何大模型。**

## 边界

- **M1–M3 的动词留在主链**（`move / goto / attack / eat / say / stop / friend / mode / ping`）——
  它们被基准录像锁住了，动一下就得重录基准。
- **M4 起的新动作一律进这个插件。** 主链的动词表就不会越长越糊。

## 规矩（和 pathfinder 插件一模一样）

- 自己一个目录、自己的 `package.json`
- 主链 `try { require(...) }`；**不在 / 加载炸 → 当没装**，对应命令回退「不认识」
- 只被主链调用，**不开 socket、不碰状态推送、不抢定时器**

## 能力

| 动词 | 参数 | 说明 |
|---|---|---|
| `sneak` | `{ms}` 或 `{on:true/false}` | 潜行。MC 机制：潜行时不会从方块边缘掉下去 —— **也是安全动作** |
| `jump` | `{count}` | 跳跃，最多连跳 5 次 |
| `jumpattack` | `{target}` | **跳劈**：先跳，等真的开始下坠，这时候才挥 → MC 暴击 ×1.5 伤害 |
| `swimdown` | `{ms}` | 游泳下降（水里按潜行键 = 下沉）。**不在水里会直接拒绝** |
| `dig` | `{p:[x,y,z], 允许挖脚下?}` | 挖一个方块，自动选工具 |
| `place` | `{p:[x,y,z]}` | 放一个方块（手上得有） |
| `craft` | `{item, count}` | 合成，先试 2×2，不行找 4 格内的工作台 |
| `use` | `{p:[x,y,z]}` | 开箱子 / 按按钮 / 开门（4.5 格内） |

## 安全护栏

- **不许挖自己正脚下那块** —— 挖完自己就掉下去了（除非显式传 `允许挖脚下`）
- **基岩 / 命令方块 / 传送门这类不许挖**
- **不在水里不许下潜**
- **跳劈要先确认真的在下坠**，跳起来立刻挥是普通伤害，白费
- 所有"自己动腿"的动作开始前会**先把控制状态清干净**
  （M2.1 的教训：边跑边挥打不中，边跑边挖也挖不准）

## 调用的样子

```jsonc
{"cmd":"jumpattack","target":"zombie"}
{"cmd":"dig","p":[10,64,5]}
{"cmd":"sneak","ms":1500}
```
