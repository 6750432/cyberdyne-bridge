# 外挂·动作面（M7b 脑侧）

> 这个目录存在的唯一理由：**给小家伙装上"合成 / 开箱子存取"的脑子，
> 而 `bridge.py` 一个字节都不动。**

## 为什么能不动主链

Python 是动态语言。`import bridge` 之后，可以在**内存里**改那几个类的属性
和方法 —— 磁盘上的文件不用碰。这就是「外挂」的 Python 版，对应手侧
`node/plugins/` 那套规矩（M2 立的：**主链只放接线，新能力全部外置**）。

机器可验证的证据（不用信我嘴上说）：

```bash
git diff 基线-M1-M7a -- bridge.py     # 输出为空 = 主链一个字没动
git status                            # 干净
```

## 这里有什么

| 文件 | 干什么 |
|---|---|
| `大脑外挂.py` | 入口。import bridge → 自检 → 看开关 → 打补丁 → `bridge.主()` |
| `自检.py` | 启动前把要挂的锚点逐条查一遍，少一条就拒绝启动 |
| `启动.sh` | 启动器（**不动** `tools/启动大脑.sh`，那是基线入口） |
| `data/items_map.json` | 物品口语名 → MC 名（第 2 步才做） |
| `prompts/*.txt` | prompt 片段（第 2 步才做） |
| `测动作面.py` | 外挂自己的断言（第 3 步才做；`tools/` 里那六套一个字不动） |

## 为什么改了 `config.json` 就多出三种本事

```
config.json → m7.expand_actions
    false（默认）→ 外挂**一个补丁都不打**，直接进主链，行为 = 基线，逐字节相同
    true         → 外挂把「合成 / 箱子里取 / 往箱子里放」挂到任务栈上
```

**这是"运行时魔法"，后来者最容易看不懂的就是这里，所以特意写出来。**
开关的**唯一出处**是 `config.json` 的 `m7.expand_actions` ——
不许在别的地方再存一份，免得两边不一致。

## 三条纪律

1. **主链一个字节都不许动。** 这个目录里所有东西都是"挂在外面"的。
   要改主链，先问主人。
2. **fail-closed：锚点对不上就拒绝启动。**
   「悄悄不生效」比当场崩掉危险得多 —— 2026-09-29 那次
   `availableGeometry()` 返回 0×0 导致一个像素都画不出来、日志却一切正常，
   就是这类静默失败。
3. **宪法不许碰。** 外挂不碰「不能直接攻击」「任务书里不许有打」这两条；
   `自检.py` 每次启动都会验一遍这两条还在。

## 回退

```bash
# ① 不启动外挂 = 基线。用原入口就行：
bash tools/启动大脑.sh

# ② 彻底回到今天的基线：
git reset --hard 基线-M1-M7a

# ③ 不想要这个外挂了：删掉整个目录即可，别的什么都不用改
rm -rf 外挂/
```

## 退出码

| 码 | 意思 |
|---|---|
| 0 | 正常（或演练跑完） |
| 1 | `--自检` 没过 |
| 2 | 自检没过，拒绝启动 |
| 3 | 开关开着但补丁还没实现 —— 拒绝启动（不许"装作开了"） |
| 4 | 找不到主链 `bridge.py` |
| 9 | 已经有一个脑在跑了（`启动.sh` 的护栏） |
