# ═══════════════════════════════════════════════════════════════
# 【任务书的步骤类型】—— LLM 能抄的动作清单
# ═══════════════════════════════════════════════════════════════
# 这一段会被外挂塞进【任务书的步骤类型】那一行。
#
# [基础] = 主链本来就认的动作，**必须跟主链一字不差**（测数据.py 会核对）。
# [扩展] = 动作面开关打开之后**多出来**的那几个。
#          外挂拼的时候是「基础」+「 / 」+「扩展」，所以这里只写多出来的部分，
#          改基础那行会自动跟着生效，不用两处维护。
#
# 改完记得跑：python3 外挂/动作面/测数据.py

[基础]
走到(p=[x,y,z]) / 挖(p) / 拾(物品,数量) / 放(p,方块) / 等(ms) / 说(文本) / 熔炉放料(p,输入,燃料) / 熔炉取成品(p,物品,数量) / wait_until(条件,等待超时_ms)

[扩展]
合成(物品,数量) / 箱子里取(p,物品,数量) / 往箱子里放(p,物品,数量,保留)
